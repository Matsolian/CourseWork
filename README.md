## 1. Выбор темы

**Тема №17:** «Диффузионная модель генерации изображений».

**Дисциплина:** «Инженерия систем искусственного интеллекта».

### 1.1. Актуальность

Генеративные модели являются одним из перспективных направлений развития искусственного интеллекта. Они позволяют создавать новые изображения на основе закономерностей, выявленных в обучающих данных.

Особый интерес представляют диффузионные модели, основанные на последовательном добавлении и удалении случайного шума. Такие модели применяются в задачах генерации изображений, обработки визуальных данных и создания синтетического контента.

Одной из основных проблем диффузионных моделей является высокая вычислительная стоимость генерации. Для получения одного изображения может потребоваться большое количество последовательных вызовов нейронной сети.

В данной курсовой работе исследуются диффузионная модель DDPM (Denoising Diffusion Probabilistic Models) и метод ускоренного семплирования DDIM (Denoising Diffusion Implicit Models).

Основное внимание уделяется зависимости качества изображений и времени генерации от количества шагов обратного диффузионного процесса.

### 1.2. Цель работы

Разработать и обучить диффузионную модель генерации изображений на основе архитектуры U-Net, исследовать качество генерации при различном количестве шагов и сравнить алгоритмы семплирования DDPM и DDIM по качеству, скорости и потреблению вычислительных ресурсов.

5. Обучить модель и провести эксперименты с различными параметрами генерации.

7. Оценить качество с помощью FID, визуального анализа и измерений производительности.
8. Экспортировать нейронную сеть в ONNX и проверить корректность инференса.

## 2. Постановка задачи

### 2.1. Общая постановка

Необходимо разработать систему, способную генерировать новые цветные изображения на основе случайного шума.

Для этого используется диффузионная модель DDPM с архитектурой U-Net.

В процессе обучения к исходному изображению добавляется гауссовский шум. Нейронная сеть получает зашумлённое изображение и номер шага диффузии, после чего обучается предсказывать добавленный шум.

На этапе генерации система начинает со случайного гауссовского шума и последовательно преобразует его в изображение.

Дополнительно реализуется алгоритм DDIM, позволяющий выполнять генерацию с меньшим количеством шагов.

### 2.2. Входные данные

**При обучении:**

- Цветные RGB-изображения размером 32×32 пикселя.
- Номер шага диффузии `t`.
- Случайный гауссовский шум.
- Параметры расписания шума (noise schedule).

**При генерации:**

- Алгоритм семплирования: DDPM или DDIM.
- Количество шагов генерации.
- Seed — начальное значение генератора случайных чисел.
- Количество генерируемых изображений.

Генерация является безусловной: модель не получает текстовый запрос или метку класса.

### 2.3. Выходные данные

Результатом работы системы являются:

- Сгенерированные RGB-изображения размером 32×32 пикселя.
- Сетка сгенерированных изображений.
- Время генерации.
- Потребление видеопамяти.
- Значение метрики FID для экспериментальных конфигураций.
- Сравнение результатов DDPM и DDIM.

### 2.4. Математическая основа

Прямой диффузионный процесс описывается выражением:

$$
x_t = \sqrt{\bar{\alpha}_t}x_0 +
\sqrt{1-\bar{\alpha}_t}\epsilon
$$

где:

- $x_0$ — исходное изображение;
- $x_t$ — изображение на шаге $t$;
- $\epsilon \sim \mathcal{N}(0,I)$ — гауссовский шум;
- $\bar{\alpha}_t$ — накопленное произведение коэффициентов сохранения сигнала.

Нейронная сеть обучается предсказывать шум с использованием функции потерь:

$$
L = \mathbb{E}_{x_0,t,\epsilon}
\left[
\|\epsilon-\epsilon_\theta(x_t,t)\|_2^2
\right]
$$

Здесь $\epsilon_\theta$ — предсказание шума нейронной сетью U-Net.

## 3. Критерии успеха

### 3.1. Функциональные критерии

Проект считается функционально завершённым, если:

- Реализована архитектура U-Net для предсказания шума.
- Модель DDPM успешно обучается на выбранном датасете.
- Система генерирует изображения из случайного шума.
- Реализованы семплеры DDPM и DDIM.
- Пользователь может изменять seed и количество шагов генерации.
- Результаты генерации сохраняются и отображаются.
- Реализован экспорт нейронной сети в ONNX.
- Web-приложение выполняет инференс с использованием ONNX Runtime.

### 3.2. Метрики качества

**Основная метрика — FID (Fréchet Inception Distance).**

FID сравнивает статистические характеристики настоящих и сгенерированных изображений в пространстве признаков нейросети Inception.

Чем меньше значение FID, тем ближе статистическое распределение сгенерированных изображений к реальному.

Дополнительные показатели:

- Визуальное качество изображений.
- Разнообразие сгенерированных образцов.
- Отсутствие грубых визуальных артефактов.
- Стабильность результатов при различных seed.

### 3.3. Предварительные целевые показатели

| Критерий             | Целевое значение                     |
| -------------------- | ------------------------------------ |
| FID                  | Менее 100 — предварительный ориентир |
| Алгоритмы            | DDPM и DDIM                          |
| Конфигурации         | Не менее 3                           |
| Измерение скорости   | Обязательно                          |
| Измерение GPU-памяти | Обязательно                          |
| Воспроизводимость    | Фиксированный seed                   |
| Экспорт ONNX         | Успешная проверка эквивалентности    |
| Web-интерфейс        | Рабочая генерация изображений        |

Значение FID менее 100 является начальной инженерной целью, а не гарантированным результатом или подтверждённым качественным стандартом. После получения первых результатов оно может быть уточнено.

Для корректного сравнения все конфигурации должны использовать одинаковую методику расчёта FID, одинаковый объём выборок и согласованные параметры предобработки изображений.

### 3.4. Критерии производительности

Планируется измерять:

- Время генерации одного изображения.
- Время генерации пакета изображений.
- Пиковое потребление GPU-памяти.
- Количество вызовов U-Net.
- Изменение FID при сокращении числа шагов.

Отдельной исследовательской целью является определение конфигурации DDIM, обеспечивающей приемлемое качество при меньшем числе вызовов нейросети по сравнению с DDPM.

### 3.5. Критерии воспроизводимости

Для обеспечения воспроизводимости экспериментов необходимо сохранять:

- Seed генератора случайных чисел.
- Конфигурацию модели.

- Версии библиотек.

### 4.2. Обоснование выбора CIFAR-10

CIFAR-10 содержит небольшие цветные изображения различных объектов и хорошо подходит для изучения алгоритмов генерации изображений.

Основные преимущества:

1. Небольшое разрешение снижает вычислительную стоимость обучения.
2. Цветные изображения позволяют исследовать генерацию RGB-данных.
3. Разнообразие объектов усложняет задачу по сравнению с простыми монохромными изображениями.
4. Набор данных широко применяется в исследованиях компьютерного зрения.
5. Доступна загрузка средствами Torchvision.
6. Имеется стандартное разделение на обучающую и тестовую части.
